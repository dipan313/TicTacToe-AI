# 🎮 Tic Tac Toe with AI (Python + Tkinter)

A GUI-based Tic Tac Toe game built in Python using `Tkinter` with three levels of AI difficulty: Easy, Medium, and Hard.

---

## 📌 Features

- ✅ GUI built using `tkinter`
- 🤖 AI with 3 difficulty levels:
  - **Easy**: Random moves
  - **Medium**: Blocks your win + randomness
  - **Hard**: Minimax algorithm (unbeatable)
- 🔁 Restart & play again anytime
- 🎨 Simple and clean UI

---


## ▶️ Getting Started

### Prerequisites
- Python 3.x installed

### Run the game
```bash
python tic_tac_toe.py
